# Facet — Spectral Glass SaaS Landing

A dark AI and SaaS launch page built around a real-time WebGL glass dispersion shader. Switch between Sphere, Aperture, Orbit and Cube right in the hero, explore an interactive three-step product demo with clickable citations, swap glass optics in the architecture showcase, toggle monthly/annual pricing and switch six colour palettes — zero 3D models or video files.

```bash

npm run dev
```

Then open http://localhost:5173.

## Build & deploy

```bash
npm run build
```

The static site is written to `dist/`. Upload it to any static host — Vercel, Netlify, Cloudflare Pages, GitHub Pages, S3 or your own server.
